# loop-engineering-lab design

## Goal

Create a minimal, independent Git repository at `/Users/tingtingguan/study/Harness/loop-engineering-lab` and a same-named public GitHub repository.

## Structure

- `README.md`: identifies the empty experiment workspace.
- `.gitignore`: excludes common macOS and Node.js build artifacts.
- `docs/superpowers/specs/`: retains this creation record.

## GitHub integration

The local repository uses `main` as its default branch and the public GitHub repository as remote `origin`. The initial commit is pushed to `origin/main`.

## Validation

Confirm the repository is clean, `origin` points to the created GitHub project, and `main` tracks `origin/main`.
