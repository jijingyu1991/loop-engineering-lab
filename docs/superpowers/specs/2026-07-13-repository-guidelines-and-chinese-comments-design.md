# Repository Guidelines 与中文注释改造设计

## 目标

为仓库新增简洁、可执行的贡献者指南，并把源码与测试中的人工英文注释翻译为适合学习项目阅读的中文注释。

## 范围

- 新增根目录 `AGENTS.md`，标题为 “Repository Guidelines”，正文保持约 200–400 词。
- 指南覆盖项目结构、开发命令、TypeScript 风格、测试、提交与 PR、安全配置。
- 明确本仓库是学习项目：关键逻辑应提供详细中文注释，重点解释设计原因、数据流、错误处理和边界条件，避免逐行复述代码。
- 只翻译 `src/**/*.ts` 与 `tests/**/*.ts` 中已有的人工英文注释。
- 排除 `dist/`、依赖、历史文档、配置数据、字符串字面量和代码标识符。

## 实施方式

逐条人工翻译现有注释，保留 `LoopStep`、`Agent`、`trace`、JSONL 等必要技术术语。翻译只改变注释文本，不调整函数签名、执行顺序、测试断言或运行时输出。

## 验证

1. 扫描 `src/` 与 `tests/`，确认不存在遗漏的英文自然语言注释。
2. 检查 `AGENTS.md` 的结构、篇幅和项目特异性。
3. 运行 `npm test`、`npm run build` 与 `npm run test:integration`，确认注释改造没有影响行为；真实 API 测试保持默认跳过。
